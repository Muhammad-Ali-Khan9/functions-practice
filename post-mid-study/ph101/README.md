# PH101 notes: vectors through rotation

GIK Institute, PH101 Applied Physics. These notes follow the mechanics topics on the course outline and the style of Young and Freedman, *University Physics*, 15th edition. Force vectors along a line also follow Hibbeler’s statics treatment, which the outline lists beside the physics texts.

Each file explains why the relation is there, how a standard calculation is set up, the mistakes that change an answer, and then gives 10 freshman-level questions with full answers.

Use $g = 9.80\,\mathrm{m/s^2}$ as a positive number. If upward is positive, free-fall acceleration is $-g$. Rotation formulas that mix a radius with an angle need radians.
